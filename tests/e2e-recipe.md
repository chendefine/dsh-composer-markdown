# 手工验收清单（e2e recipe）

对运行中的 DSH Web（默认 http://127.0.0.1:3080，本部署 https://dsh.devoi.net）逐条执行。可用
playwright-cli 驱动；键盘事件需是真实 keydown（`pressSequentially` / `keyboard.press`，
不要 `fill` —— fill 不触发 keydown）。

**按键映射（v1.1 起）**：列表编辑手势在 **Shift+Enter** 与 **Tab/Shift+Tab**（层级缩进，v2.8）
上；**Enter = 原生发送，从不拦截**；未命中场景的 Shift+Enter = 原生软换行；
非列表行的 Tab/Shift+Tab = 原生（焦点移动）。

前置：插件已安装（`dsh plugin --profile web add link:…` + 重启 web 服务），
浏览器已刷新，存在一个可用会话（composer 可聚焦）。建议新建一个测试会话。

## R1 无序列表续行（Shift+Enter）

1. 点击 composer 聚焦，清空草稿。
2. 依次输入：`- 苹果`，按 **Shift+Enter**。
   - ✅ 出现第二段，行首自动带 `- `，光标停在前缀后。
   - ✅ composer 出现两个段落（`querySelectorAll('[data-composer-input] p')` ≥ 2）。
3. 输入 `香蕉`，按 Enter 发送。
   - ✅ 发送后的用户消息字面包含两行：`- 苹果` / `- 香蕉`。
4. `* ` 与缩进：新草稿输入 `  * 缩进项` + Shift+Enter → `  * ` 续行。
5. **软行续行（v1.8）**：清空，输入 `intro` + **Shift+Enter**（原生软换行），输入 `- 苹果` + **Shift+Enter**。
   - ✅ 同段内 `- 苹果` 下方出现新软行，行首自动带 `- `（此前该场景只会再插一个软换行，永远无法触发列表）。
   - ✅ 继续 `香蕉` + Shift+Enter → 再续 `- `；空项上再按 Shift+Enter → 前缀被移除、光标留在该空行。
   - ✅ 光标行下方还有其他软行文本时，新前缀行插在光标行之后，其余文本顺延下移。
   - ✅ 发送 → 消息字面包含全部行与 `- ` 前缀（`\n` 分隔）。
6. **行中间截断（v1.12）**：清空，输入 `- one two`，光标移到 `one ` 之后（`two` 左侧），
   按 **Shift+Enter**。
   - ✅ 变为 `- one ` 与新 item `- two` 两行（光标后的 `two` 移到新行、接在新 `- ` 之后）；
     段落列表与软行列表（`head:` + 软换行 + `- one two`）同样生效。
   - ✅ 光标在**行尾**按 Shift+Enter → 维持原行为（下方新增空 `- ` 行，原行不动）。
   - ✅ 光标在**前缀内部**（如 `1` 与 `.` 之间）或行首 → 维持原行为（下方新增，不截断）。

## R2 有序列表编号（Shift+Enter）

1. 清空，输入 `1. 第一步` + Shift+Enter → `2. ` 自动出现。
2. 输入 `第二步` + Shift+Enter → `3. ` 自动出现。
3. 清空，输入 `3. 起始` + Shift+Enter → `4. `（非 1 起始也递增）。
4. 发送 → 消息字面为 `1. 第一步\n2. 第二步…`。
5. **软行编号（v1.8）**：清空，输入 `intro` + Shift+Enter，输入 `1. 第一步` + Shift+Enter → 软行 `2. ` 自动出现；继续输入递增。
6. **非首段编号**：先构造两个以上普通段落/围栏（如 ``` 骨架后出块），在下方段落行首输入 `1. x` + Shift+Enter → 照常续行。
7. **中间插入整体顺延（v1.11）**：构造 `1. one / 2. two / 3. three`（段落或软行列表均可）。
   - 光标移到 `1. one` 行尾，Shift+Enter → ✅ `1. one / 2. ␣ / 3. two / 4. three`（新行拿 `2. `，
     下方各成员依次 +1，整组连续且不重复；光标落在新行前缀后）。
   - 一次 **Ctrl+Z** → ✅ 连插入带顺延一并还原（同一撤销步）。
   - 光标在中间 `2. two` 行尾插入 → ✅ `1. one / 2. two / 3. ␣ / 4. three`。
   - 光标在**末行**行尾插入 → ✅ `… / 3. ␣`（下方无成员，无需顺延）。
   - 软行列表（`head:\n1. a\n2. b\n3. c` 单段）在 `1. a` 行尾插入 → ✅ `head:\n1. a\n2. ␣\n3. b\n4. c`。
   - 多位数：`9. a / 10. b / 11. c` 在 `9. a` 后插入 → ✅ `9. a / 10. ␣ / 11. b / 12. c`（位数变化正确）。
   - 手动跳号被连续化：`1. a / 5. b` 在 `1. a` 后插入 → ✅ `1. a / 2. ␣ / 3. b`。
   - 无序列表插入 → 无顺延（本就无序号）；普通行/缩进变化/围栏截断顺延范围。
   - **行中间截断 + 顺延联动（v1.12）**：`1. alpha beta / 2. gamma`，光标移到 `alpha ` 之后
     （`beta` 左侧）按 Shift+Enter → ✅ `1. alpha  / 2. beta / 3. gamma`（尾部 `beta` 移入新
     item，下方顺延）；软行列表同样生效（`h:\n1. aa bb\n2. cc` 在 `aa ` 后截断 →
     `h:\n1. aa \n2. bb\n3. cc`）；一次 Ctrl+Z 整体还原。

## R2b 有序列表序号规整（v2.6：组内恒连续，状态驱动）

前置认知:v2.6 起**不变式**取代了旧的「证明是删除才接续」:每个有序组(同缩进、
不在围栏内的有序**视觉行**)**恒为其首成员起的 `1. … n.`**。规划是当前草稿的纯函数,
无跨扫描记忆——删行接上、**组被隔断则后组从 1. 重起**、**隔断行删除则两组合并累加**、
粘贴/撤销产生的任何形状都按现状规整;代价是组不能保留非 1 起始号与手动跳号
(手改序号立即回弹——连续性即契约)。**v2.7 嵌套感知**:更深缩进的行(嵌套子列表、
条目折行内容)只**挂起**外层组——外层缩进回归即续接计数;空行、围栏、以及缩进
不深于本组的普通行/无序行才真正断组。段落列表与软行列表(续行/整段粘贴形成的同段多行
列表)同等按**视觉行**参与。（**续行插入**的下方顺延在 R2 第 7 步,是手势内的同一更新,
不依赖本规则。）

1. 清空，构造 `1. one` / `2. two` / `3. three` / `4. four`（Shift+Enter 续行）。
2. 选中 `2. two` 行内文本（不含换行；可拖选）后 Backspace 删空，再 Backspace 删掉空行。
   - ✅ 下方自动接上：`3. three` → `2. three`、`4. four` → `3. four`，`1. one` 不动。
   - ✅ Ctrl+Z 一次 → 删除与改号**一并还原**（同一撤销步）。
   - 注：三击选中整行（含换行）删除时，浏览器把后段并入被删行节点，幸存行号如有
     偏差会在下一轮 restyle 规整——所见即所得。
3. 删除首行 `1. one` → 剩余行重排为 `1.` `2.`（组恒 1 基）。
4. 删除末行 → 其余行**不变**（本就连续，无操作）。
5. **隔断重起（v2.6 核心新行为）**：`1. a` / `2. b` / 普通行 `note` / `3. c`（或把
   `note` 行直接粘贴进去）→ ✅ `3. c` **立即变 `1. c`**（后组从 1 重起；到达路径
   无关——手打、粘贴、撤销都一样）。
6. **合并累加（v2.6 核心新行为）**：构造 `1. a` / `2. b` / `note` / `1. c` / `2. d`
   （各自从 1 起编），删除 `note` 行 → ✅ 四行连成一组：`1. a` / `2. b` / `3. c` /
   `4. d`（完整地从最开始的 1 连续累加，而非各自排序）。
7. 手动改号回弹：把 `2. two` 的 `2` 改成 `5` → ✅ 下一拍**回弹为 `2.`**（连续性契约，
   有意取舍）。
8. 非 1 起始归一：粘贴 `5. x` / `6. y` → ✅ 规整为 `1. x` / `2. y`。
9. 懒编号 `1.` `1.` `1.` → ✅ 规整为 `1.` `2.` `3.`（重复序号不可能存在）。
10. **空 item 退出的组合流（用户报告场景）**：`1. a` / `2. b` / `3. c`，光标在
    `2. b` 行尾按 Shift+Enter → 得空 item `3. `（下方 `4. c`）；再在该空 item 上按
    Shift+Enter 退出 → ✅ 终态 `1. a` / `2. b` / 空行 / **`1. c`**（隔断重起），
    光标落在空行上可继续输入。
11. **软行列表**：输入 `列表:` 后 Shift+Enter，再 `1. one`、续行 `2. two`、续行
    `3. three`（同段软行）。删 `2. two`（两步）→ ✅ `3. three` → `2. three`；
    在软行间插入空行 → 后段从 `1.` 重起。
12. **整段粘贴的软行列表**：粘贴 `1. a\n2. b\n3. c`（一段三行），删除中间行
    （两步）→ ✅ `3. c` → `2. c`。
13. **嵌套挂起与续接（v2.7）**：
    - 构造 `1. a`，Shift+Enter 后在行首敲两空格 + `1. b`（或直接粘贴
      `1. a\n  1. b\n2. c`）→ ✅ 外层不受嵌套影响：`2. c` **保持 `2.`**（此前会被
      重置为 `1. c`）；嵌套行自身按其缩进独立规整（`  2. b` → `  1. b`）。
    - 更深的无序/普通行同样只挂起：`1. a / ␣␣- b / 1. c` → ✅ 尾行回弹为 `2. c`。
    - 多层嵌套 `1. a / ␣␣1. b / ␣␣␣␣1. c / ␣␣3. d / 3. e` → ✅ `d→2.`（其组内）、
      `e→2.`（外层跨两个嵌套段续接）。
    - 空行仍断组：`1. a / ␣␣1. b / ␣(空行) / 3. c` → ✅ 尾行**重启为 `1. c`**
      （挂起不越过空行）；同层无序行同样断组（`1. a / ␣␣1. b / - x / 3. c` → `1. c`）。
    - 粘贴整份嵌套 Markdown（`1. one / ␣␣1. nested / ␣␣2. nested / 2. two /
      ␣␣- bullet / 3. three`）→ ✅ 全部原样保留（外层 1..3 从未被重置）。
14. 发送 → 消息字面为规整后的文本（序号规整是真实的文本改写，所见即所发）。

## Enter 原生发送（最高优先级回归）

1. 清空，输入 `- 未完的列表项`，按**普通 Enter**。
   - ✅ 消息**立即发送**（不续行、不插入段落）——原生行为完全保留。
2. 草稿构造未闭合围栏（``` + Shift+Enter 后只填一行），光标留在围栏内按**普通 Enter**。
   - ✅ 照常发送。

## E2 空列表项退出

1. 清空，输入 `- ` + **Shift+Enter** → 前缀被移除，留下空段，未发送；空段上继续
   输入正常（v2.3 空块重置保活）。
2. 空段上按普通 Enter → 走 DSH 原生 Enter（空草稿无动作/发送），不崩溃。
3. **有序空 item 在列表中间（v2.6）**：`1. a` / `2. ` / `3. c`，光标在 `2. ` 之后
   按 Shift+Enter → ✅ 前缀移除留空段、光标在空段上可输入，且下方 `3. c` **重起
   为 `1. c`**（隔断重起，见 R2b 第 10 步的完整流）。

## MK 列表原子整体删除（v1.10；v2.8 起缩进并入原子、Backspace 后归层级阶梯）

1. `- xyz` / `* xyz`：光标在 `- `/`* ` **之后**按 Backspace → 只剩 `xyz`
   （顶层 Backspace = 取消列表，见 LL 节；嵌套行 = 升一级）。
2. **Delete 反向（v2.8 缩进并入）**：`1. abc` 行首按 **Delete** → 整个 `1. ` 前向删净；
   `  1. abc`（两空格缩进）行首按 Delete → **`  1. ` 整体**一次删净（缩进无法逐字符删）。
3. **裸前缀**：只有 `- ` 时光标在其后按 Backspace → 前缀整体消失，留空段（可聚焦可输入）。
4. **原生行为保留**：光标在 `1.` 与空格**之间**（offset 2）按 Backspace/Delete → 原生删
   `.`（得 `1 abc`；该位置正常情况下不可达，需点击落入）；光标在内容中间 → 原生逐字符；
   带选区按 Backspace → 原生删选区。
5. **围栏内不是列表**：```` ``` ```` 围栏内的 `- x` / `1. x` 行按 Backspace/Delete → 原生
   逐字符（代码内容，永不成列表）。

## LL 列表层级缩进阶梯（v2.8：Tab 降级 / Shift+Tab 或前缀后 Backspace 升级；v2.9 降级上限）

前置认知：列表「缩进 + 前缀」是一个**原子**；每级缩进 2 空格；升降级**整棵子树递归联动**；
顶层再升 = **取消列表**回归普通文本（删前缀留正文）。子树边界 = 下方**更深层级行**，
遇空行 / 围栏 / 不更深行即止。**降级上限（v2.9）**：任何项最多处于其**父级**
（上方最近的列表项行，普通行跳过；空行 / 围栏隔断查找）的**下一级**——
超限的 Tab（含列表首项）为「认领但不动」的空操作。

1. **Tab 降级 + 子树联动**：逐行构建 `- a`、`- b`、`  - b1`、`    - b2`、`- c`
   （深层两行可先手敲空格，或先用本节 2/3 在别的行上造出）。光标放 `- b` 行内
   **任意一处**（含内容中间、行尾）按 **Tab** → ✅ `- a` 不动，`- b / ␣␣- b1 /
   ␣␣␣␣- b2` 整体 +2（b 降到 a 的下一级，子树随行），兄弟 `- c` 不动；
   再按 **Ctrl+Z** → ✅ 一次整体还原（整棵子树一个撤销步）。
2. **Shift+Tab 升级**：接上例（`- a / ␣␣- b / ␣␣␣␣- b1 / ␣␣␣␣␣␣- b2 / - c`），
   光标在 `  - b` 行内任意处按 **Shift+Tab** → ✅ 回到 `- a / - b / ␣␣- b1 /
   ␣␣␣␣- b2 / - c`（b 及其子树各 −2）。
3. **前缀后 Backspace = 升级**：`  - b`（嵌套行）光标移到 `- ` **之后**（Home → ×2）按
   **Backspace** → ✅ 变为 `- b`（升一级）；等价于该行的 Shift+Tab。
4. **顶层取消列表**：`- a` / `  - b` / `    - c`，光标在 `- a` 行内任意处按 **Shift+Tab**
   （或 `- ` 之后按 Backspace）→ ✅ 变为 `a`（普通文本行）/ `- b` / `  - c`（子层级同步
   升一级）；发送 → ✅ 消息字面为 `a\n- b\n  - c`。
5. **降级上限（v2.9）**：
   - 清空输入 `- a`（仅一项，列表首项），光标行内任意处按 **Tab** → ✅ **无任何变化**，
     且**焦点仍留在输入框**（按键被认领但不动；连续多按同样不动）。
   - `- a` / `  - b`，光标在 `  - b` 行按 **Tab** → ✅ 不动（b 已处于父级 a 的下一级，
     到达上限）；对 `- a` 按 Tab 同样不动（首项无父级）。
   - `- a` / `  - b`，先对 `- a`……仍不可降（首项）；正确加深姿势：**先有兄弟**——
     `- a` / `- b` 对 `- b` 按 Tab（✅ 得 `- a / ␣␣- b`），再要更深需先给 `- b` 造出
     兄弟（`- a / - b / - c` → 对 `- c` 按 Tab → `␣␣- c`，再对 `- b`……到上限即止）。
   - 空行 / 围栏隔断父级查找：`- a`、空行、`- b`，对 `- b` 按 Tab → ✅ 不动（空行上方
     无父级）；`- a`、``` 围栏、`- b` 同理。
6. **有序组联动重排**：`1. a` / `2. b`，光标在 `2. b` 行内按 **Tab** → ✅ `1. a` /
   `  1. b`（嵌套组按不变式独立从 `1.` 起）；光标在 `  1. b` 行按 **Shift+Tab** → ✅
   `1. a` / `2. b`（回到同组连续）。
7. **取消列表隔断有序组**：`1. a` / `2. b` / `3. c`，对 `2. b` 取消列表（`2. ` 之后按
   Backspace）→ ✅ `1. a` / `b` / `1. c`（普通行隔断，后组从 `1.` 重起——编号不变式
   的既定后果）。
8. **子树边界**：`- a`、`- b`、空行、`  - c` → 对 `- b` 按 Tab → ✅ `- b` 变 `  - b`，
   空行后的 `  - c` **不动**（空行终止子树）；下方有 ``` 围栏时同理（围栏行及其中内容
   永不移位）。
9. **缩进不可进入**：`  - b` 行，用鼠标点击两个缩进空格中间 → ✅ 光标被归位到行首
   （不在缩进内部）；行首按 **→** → ✅ 一次跨过 `  - ` 落到 `b` 左侧；`b` 左侧按 **←**
   → ✅ 一次跳回行首（不逐字符穿过缩进/前缀）。
10. **长按不失控**：按住 Tab 不放 → ✅ 降一级后停在层级上限（重复键仍被认领、为空操作，
    焦点不跳走）；按住 Shift+Tab → ✅ 每次重复升一级，顶层项取消列表后该行回归普通文本、
    再按才回到原生行为。
11. **非列表行让位**：普通文本行按 Tab/Shift+Tab → ✅ 原生行为（焦点移动），绝不拦截；
    触发菜单打开时按 Tab → ✅ 菜单自己的 Tab 行为。
12. **软行列表同效**：`h:` + Shift+Enter + `- a` + Shift+Enter + `- b`（同段软行），
    光标在软行 `- b` 行内按 Tab → ✅ `h:\n- a\n  - b`，光标随行平移（块内扁平偏移正确）。

## LS 列表标记渲染 + 方向键原子跨越（v2.2）

前置认知：列表「缩进 + 前缀」（`␣␣- `/`* `/`N. `）是一个**原子**（v2.8 起缩进并入）——
删除整体删、方向键整体跨、渲染与正文不同（所见仍所发：标记字节逐字保留）。
围栏内的标记样式是代码，一律不适用。

1. **有序序号等宽**：清空，输入 `1. 第一步`。
   - ✅ 序号数字 `1` 呈等宽代码字体（与行内代码同 `--ds-font-family-code`），
     `.`、空格与正文同字体；多位序号（构造到 `10.` `11.`）每位数字都等宽。
   - ✅ `document.querySelector('[data-composer-input] .dmd-list-num')` 存在，
     其 `textContent` 恰为序号数字字符。
